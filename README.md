# دستیار هوش مصنوعی کسب و کار

این پروژه یک دستیار هوش مصنوعی برای کمک به مدیریت و ارتقای کسب و کار شما در زمینه فروش لوازم تحریر لوکس است. این دستیار به شما کمک می‌کند تا محتوای خود را در شبکه‌های اجتماعی منتشر کنید، رقبای خود را تحلیل کنید و با استفاده از هوش مصنوعی، مشاوره‌هایی برای بهبود کسب‌وکار خود دریافت کنید.

## قابلیت‌ها

*   **انتشار محتوا:** انتشار همزمان محتوا در اینستاگرام و تلگرام.
*   **تحلیل رقبا:** شناسایی و تحلیل وب‌سایت‌های رقبا برای پیدا کردن ایده‌های جدید.
*   **مشاوره هوشمند:** ارائه مشاوره برای ارتقای کسب و کار با استفاده از مدل زبان Llama3.
*   **رابط کاربری وب:** یک داشبورد تحت وب برای مدیریت دستیار و مشاهده تحلیل‌ها.
*   **بات تلگرامی:** یک بات تلگرامی برای تعامل آسان با دستیار از طریق موبایل.

## پیش‌نیازها

قبل از شروع، مطمئن شوید که نرم‌افزارهای زیر را روی سیستم خود نصب کرده‌اید:

*   **Python 3.8+:** زبان برنامه‌نویسی اصلی پروژه.
*   **Ollama:** برای اجرای مدل زبان Llama3. (مطمئن شوید که مدل `llama3` را با دستور `ollama pull llama3` دریافت کرده‌اید)
*   **اختیاری: XAMPP:** برای مدیریت وب سرور و پایگاه داده (در این پروژه از SQLite استفاده شده و نیازی به XAMPP نیست).

## مراحل نصب و راه‌اندازی

1.  **کلون کردن مخزن:**
    ```bash
    git clone <URL_مخزن_شما>
    cd <نام_پوشه_پروژه>
    ```

2.  **ایجاد و فعال‌سازی محیط مجازی:**
    ```bash
    python -m venv venv
    # On Windows
    venv\Scripts\activate
    # On macOS/Linux
    source venv/bin/activate
    ```

3.  **نصب وابستگی‌ها:**
    ```bash
    pip install -r requirements.txt
    ```

4.  **تنظیم متغیرهای محیطی:**
    یک فایل به نام `.env` در ریشه پروژه ایجاد کرده و اطلاعات زیر را در آن قرار دهید:
    ```
    TELEGRAM_BOT_TOKEN="<توکن_بات_تلگرام_شما>"
    TELEGRAM_CHAT_ID="<آیدی_کانال_تلگرام_شما>"

    # اطلاعات ورود به اینستاگرام (اختیاری)
    INSTAGRAM_USERNAME="<نام_کاربری_اینستاگرام_شما>"
    INSTAGRAM_PASSWORD="<رمز_عبور_اینستاگرام_شما>"
    ```
    **مهم:** برای دریافت توکن بات تلگرام، با `BotFather` در تلگرام صحبت کنید.

5.  **ایجاد پایگاه داده:**
    برای ایجاد فایل پایگاه داده و جداول آن، دستور زیر را اجرا کنید:
    ```bash
    python -m app.database
    ```

## نحوه استفاده

### اجرای برنامه اصلی (تحلیل و مشاوره)

برای اجرای اسکریپت اصلی که رقبا را پیدا کرده و مشاوره اولیه را ارائه می‌دهد، دستور زیر را اجرا کنید:
```bash
python -m app.main
```
این اسکریپت به صورت خودکار اجرا شده و نتایج را در کنسول و پایگاه داده ذخیره می‌کند.

### اجرای وب‌سایت

برای اجرای رابط کاربری وب، دستور زیر را اجرا کنید:
```bash
flask --app app.web_app run --debug
```
سپس مرورگر خود را باز کرده و به آدرس `http://127.0.0.1:5000` بروید.

### اجرای بات تلگرامی

برای اجرای بات تلگرامی، دستور زیر را در یک ترمینال جداگانه اجرا کنید:
```bash
python -m app.telegram_bot
```
سپس به تلگرام رفته و با بات خود صحبت کنید.
